# Quest dialog example: persuasion, language, logic, and a resumable chain

The dialog `quest_demo` (NPC Wren the Archivist, tag `quest_wren`) shows four quest types built from three shared scripts. It is generated by `tools/quest_demo.py`; edit the Python and rerun it rather than the JSON.
Wren spawns beside the first plot giver in an area a player enters (`QuestDemoSpawn` in `lang_demo_inc.nss`), next to the goblin Gruk.

## The scripts

| Script | Role | Parameters |
|---|---|---|
| `cond_qd` | link condition | `quest`, `op` (`stage_eq`, `stage_lt`, `stage_ge`, `flag`, `noflag`, `gold`, `attempts_ge`, `leads_eq`, `leads_ge`, `finale_ready`), `value`, `name`, `not` |
| `act_qd` | node action | `op` (`stage`, `setflag`, `attempt`, `roll`, `pay`, `complete`, `reset`), `quest`, `skill`, `dc`, `name`, `gold`, `xp` |
| `cond_lang_know` | language gate | `language`, `level` (1-6), `not` |
| `qd_inc` | shared state helpers | |

Parameters are Key/Value pairs on the dialog link (`ConditionParams`) or node (`ActionParams`), read with `GetScriptParam`.

## State and resuming

State sits in local ints on the PC, saved in the character file, so every quest resumes after logout:
`qd_<quest>_stage` (0 new, 1 accepted, 9 done) and `qd_<quest>_<flag>` for named flags.
Each quest also has a journal category `qd_<quest>` with entry 1 (accepted) and 9 (done).
Every quest has a "continue" reply (stage 1) next to its "start" reply (stage 0), so Wren picks the conversation up where the player left it.
The hub reply "[Test] Forget all my quest progress" clears everything for repeat testing.

## 1. The Miller's Debt (persuasion)

Story: Old Tolliver the miller owes the Guild eighty gold. Collector Brannoc seizes the mill at dawn. Tolliver saw which road the lost caravan took, but he will say nothing while his mill is at risk. The player speaks to Brannoc.
Branches at the toll gate:
- Persuade (DC 15), one try.
- Intimidate (DC 18), one try.
- Pay 80 gold (shown only if the player has it).
- A failed roll leads to "Try something else", so a failure closes one approach and leaves the others open.
Every success completes the quest (XP, gold, a caravan lead). The roll message shows the d20, skill rank and DC.
Pattern shown: skill checks on a reply action, result flags (`ok_*`, `fail_*`, `tried_*`) that gate the next node and hide used options.

## 2. The Goblin Envoy's Letter (language)

Story: A goblin envoy, Skritt, left a sealed letter and ran. Wren cannot read Goblin. The letter says the Red Hand, not the goblins, took the caravan, and asks for a meeting at the broken bridge.
The player reads the letter and the result depends on Goblin fluency, tested in order:
- Fluency 6: the full translation, quest complete.
- Fluency 3-5: a garbled gist; the player may roll Lore (DC 18) to fill the gaps for a smaller reward, or study more Goblin and read again.
- Fluency 1-2: a few words; Lore (DC 25) can still decipher the glyphs.
- No Goblin: nothing readable; the same Lore route, plus a hint to find a Goblin book.
Pattern shown: several NPC lines on one reply, each behind `cond_lang_know` at a different level, with the first passing line shown. Rereading after studying more Goblin gives a better result, and a failed guess sets `misread` without closing the quest.

## 3. The Stolen Ledger (logic)

Story: The Guild ledger vanished from a locked archive. The Cook, the Guard and the Scribe hold the keys. The Cook says "The Scribe took it", the Guard says "I did not take it", the Scribe says "The Cook is lying". Exactly one statement is true. (Answer: the Guard.)
- Each wrong suspect gets a specific reason it fails.
- Wrong answers are counted; a hint reply appears after two.
- No skill helps; the player reasons it out.
Pattern shown: puzzle answers as replies, per-answer feedback, attempt counter, hint unlock.

## 4. The Lost Caravan (interoperable, resumable chain)

Story: A merchant caravan left the Archive three days ago and vanished. The three quests above each produce one lead: the road the miller saw, the goblin letter, the ledger's route. All point to the broken bridge, where the Red Hand ambushed the caravan.
- The quests can be done in any order, before or after accepting the caravan job, and each can be left and resumed.
- Completing a quest adds `lead_<quest>` to the caravan quest. The hub text changes with 0, 1, 2 or 3 leads held.
- With three leads and the caravan accepted, "[Report] I hold all three leads" opens the finale (largest reward).
Pattern shown: one quest consuming the completion of others through flags, with a hub that loops back and reflects overall progress.

## Reading the dialog

Open `src/dlg/quest_demo.dlg.json` or the generated script. Every node name in `tools/quest_demo.py` (`E_` entries, `R_` replies) matches one dialog node, and each link lists its condition. Entries: 26, replies: 26.
