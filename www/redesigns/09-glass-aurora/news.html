Transmissions from across the Arlandian frontier — server announcements, development logs, and community milestones.

02 March 2020

UOA server REOPENING under new Management. Now with backwards AMERICAN dates... Sorry.

by Qlippoth

I'm trying to get UoA back up and running under NWN:EE. All the necessary hak files are available in the Downloads section. I hope to have NWN:EE NWSync working shortly, in which case you won't need to download haks, but for now the (rather old) haks are available. Be sure to check out the Crafting page so you know what you are looking for and what you can craft! The game world is a random grid of areas, using templates, with some randomly placed cities and other points of interest. You can craft items, build homes and Guild Halls, factories, even Airships and Spaceships! I'm happy to share all of this — if you want to HELP, get in touch. Otherwise, feel free to ask questions about the module!

12 August 2011

UOA server closed

by TheRack

We have to announce that the official UOA server is now closed, due to lack of players! All the necessary files to play or host the UOA world are now available in the Downloads section. Be sure to read the instructions to set up a server. We would be pleased to know if another server is set up with the UOA system.

Beta-testing running

30 May 2010

The alpha testing has begun

by TheRack

Now is time for some news. I have started to test the world and the system over the past few weeks, slowly because of lack of time. Solo play already brings a lot of fun. A lot of bugs have already been corrected. The multiplayer and DM modes should increase the fun even more. PS: the Arland map has been updated with the actual map I'm playing on my local server.

09 February 2010

THE MODULE IS FINISHED !!!

by TheRack

After a HUGE amount of work — more than 12 hours, 7 days a week, for 3 months — of scripting, modeling and testing, everything is ready for the first alpha testing. Check the Screenshots section for new shots, especially from the planets and from space. Check the Domains section too — the "factory" page shows what can be done with the domain factory. PS: don't forget to enter the word "dm" in the DM area field to see the planet maps!

10 January 2010

A new year begins, and a new world appears

by TheRack

Happy new year to the Neverwinter Nights community! Most of the main features have been built and alpha testing is only a few days or weeks away. Still to do: player feats; missing interests (castles, ruins, animal reserves, resource mountains, amusement places, domains); player domains & structures; other minor improvements. Beta testing will be possible in a few weeks!

20 November 2009

Huge improvements and... first screenshots

by TheRack

I have worked really hard to stabilise the ground system and make future implementation easier. This new website is now interactive. Check the right menu (dynamic maps) — you can visit the planets, e.g. Arland, but you'll only see discovered areas... unless you connect as a DM (enter "dm" in the DM area) to see everything. All planet info comes from an example database. Register on the forum and give us your first impressions!

25 October 2009

Interests, domains, races

by TheRack

In the last weeks we've worked on interest points (dungeons, towers, towns, etc.) generated randomly on planets (fully customizable), on player domains — real activity centers for economic, social and military activities — and on new playable races: goblins, ogres, orcs, minotaurs and even trolls! Next time we'll post screenshots of the first tiles.

17 July 2009

First star system built

by TheRack

The design of the module is progressing slowly due to lack of time, but the project is still alive. The first star system has been discovered totally by the Arlandia spies — we now know there are 11 planets and 8 moons in the Meth system.

The website of the new world "Universe of Arlandia" has been launched. Updates will be shown here as well as progress on the module design. The "Universe of Arlandia" will be a rich and unlimited module/persistent server/world for Neverwinter Nights. No size restriction — the universe is infinite!
